# Rawafid Online Academy

Website for live Zoom classes in Quran and Tajweed, Islamic Studies, Arabic and English.

English, Arabic, French and Spanish. Includes two-pass welcome flight, raised 3D cards and buttons, Rawafid logo cursor, and Google Form registration.

Static site. Publish the repository root, with no build command. For local preview run `python -m http.server 8000`.
